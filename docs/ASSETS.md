# Recursos del módulo

Se copiaron **13 fondos y 15 iconos SVG** del módulo local `redvelvet-crafting-pf2e/assets`, a petición del autor. Las copias se sirven desde este módulo; no requieren instalar PF2e ni contactar Pinterest/Catbox. Se conserva la identidad gráfica propia por oficio, cultivo y despiece. El fichero `assets/Redvelvet Crafting System.png` ya formaba parte de D&D5e.

Los sufijos `original` y `generated` de los recursos heredados conservan sus nombres anteriores; no constituyen una atribución nueva ni una declaración de autoría de terceros. Su procedencia previa corresponde a la biblioteca del autor del módulo.

Nuevo fondo: `assets/backgrounds/workshop-dnd5e.png`, generado con la herramienta **image_gen** integrada, sin API externa ni clave del usuario. Se conservó el original generado fuera de la carpeta del módulo.

Prompt utilizado:

> Use case: stylized-concept. Asset type: production background for a fantasy tabletop crafting UI, RedVelvet Crafting D&D5e. Create one polished landscape illustration of a medieval artisan workshop at dusk: a glowing blacksmith forge and anvil on the left, a tidy oak workbench with precision hand tools in the foreground, glass alchemy vessels and stacked leather on shelves to the right. No people. Rich believable metal, wood, leather and glass textures, refined painterly realism, warm amber firelight against deep charcoal shadows, atmospheric but crisp at UI scale. Composition: landscape 1536x1024 if available, focal objects around the outside, a quiet dark central area with generous negative space for a readable overlay of menu buttons. The workshop must feel crafted and premium, not cartoonish. No text, letters, numbers, icons, border, watermark, modern machinery or recognizable game IP. This is a new bitmap project asset; return the generated image and saved file path if available.

Audio: **20 OGG originales**, sintetizados mediante resonancias modales, ruido filtrado, transitorios y una cola estéreo corta. No se utilizaron grabaciones de videojuegos, música, muestras externas ni sonidos de Dice So Nice/Maestro. Se generan con `tools/generate_audio.py`, semilla fija 50213; estéreo, 48 kHz, pico objetivo -6 dBFS, duración aproximada 0.22–0.72 s y fundidos para evitar clics. Son diseño sonoro sintético, no grabaciones de foley real.
